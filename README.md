# Library Loan Desk

A responsive library management interface built with React and Tailwind CSS.

## About the Project

Library Loan Desk is a frontend project designed to help organize a library's book collection and demonstrate basic book loan management.

## Features

- View library inventory and overview statistics
- Browse books and check copy availability
- Search and filter books
- Manage book records
- Track loans and returns
- Responsive interface for desktop and mobile

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- Local Storage (planned for frontend data persistence)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aminrasooli2007-svg/library-loan-desk.git
```

### 2. Open the project folder

```bash
cd library-loan-desk
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
